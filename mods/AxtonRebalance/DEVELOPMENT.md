## Sabre Turret damage progression (0.1.1)

The mod applies a linear bonus to the turret's existing damage inputs: +30% at GameStage 1 and +275% at GameStage 90 (level 80 OP10). The formula is `0.30 + (stage - 1) * (2.75 - 0.30) / 89`, clamped at the endpoints; each input is multiplied by `1 + bonus`. This keeps the asset's existing initialization definition and any global level scaling underneath it.

The four identified inputs are turret weapon `InstantHitDamage`, Nuke projectile `Damage`, Nuke explosion `DamageFormula`, and Nuke `StatusEffectDamage`. The mod does not modify turret health, shield, fire rate, cooldown, or other skills. Scorched Earth rockets have not been independently traced and require an in-game check.

The local Axton controller is checked once per second. Native damage values are captured per asset address and reapplied only when the target differs, including when assets stream in after the first check. No pawn or world UObject is cached. The fields are shared game definitions, so character switching in the same process and co-op need gameplay validation. Replacing or disabling this native patch requires a game restart.

The damage field paths were identified with the game data and checked against the installed UCP patch as a reference. The bonus curve, runtime application, and tests were written for this project. No UCP formulas or constants were transplanted into the module.

## Working principles

- Verify each proposed skill change against the native game data and behavior before editing it.
- Keep runtime hooks narrow, lifecycle-aware and scoped to the local player where appropriate.
- Preserve native behavior unless a change explicitly replaces it.
- Keep player-facing text in English to match the game.
